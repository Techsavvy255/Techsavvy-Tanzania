# Techsavvy Tanzania Website

**Youth-driven technology platform empowering young people through technology, innovation, and digital skills.**

## 🚀 Overview

Techsavvy Tanzania is a comprehensive web platform offering technology training, innovation projects, and community engagement for young people in Tanzania.

**Website:** https://techsavvy255.github.io/Techsavvy-Tanzania/

## 📋 Features

- **Programs**: Technology Training, Innovation & Projects, Community
- **Courses**: AI & ChatGPT, Graphic Design, Web Development, Networking, Cybersecurity, Digital Marketing
- **Projects**: DaLink, SimuPulse, Techsavvy Learning
- **Articles**: Technology insights and tutorials
- **Admin Dashboard**: Manage applicants and analytics

## 🛠️ Technology Stack

- HTML5 with semantic markup
- CSS3 with modern design
- Vanilla JavaScript (No frameworks)
- GitHub Pages hosting
- GitHub Actions for CI/CD

## 📱 Responsive Design

- Desktop optimized
- Mobile-friendly
- Tablet compatible
- Accessibility features (WCAG)

## 🔍 SEO Optimization

- ✅ Meta tags and descriptions
- ✅ Open Graph tags (Social media)
- ✅ Schema markup (JSON-LD)
- ✅ Structured data for courses
- ✅ robots.txt and sitemap.xml
- ✅ Canonical URLs
- ✅ Mobile responsive
- ✅ Fast loading (static files)

## 📊 Admin Dashboard

- Applicant management
- Application analytics
- Status tracking (Pending, Accepted, Rejected)
- Filter and search functionality
- Google Forms integration ready

## ⚙️ Setup & Deployment

1. Clone repository
2. Edit content in HTML files
3. Push to main branch
4. GitHub Actions automatically deploys to Pages
5. Live at: https://techsavvy255.github.io/Techsavvy-Tanzania/
